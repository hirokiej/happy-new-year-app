# Happy New Year Celebration App

## Description

This application displays an animation to celebrate the New Year.

## Requirements

Language:

- Ruby

Required Gems:

- artii
- Rainbow

## Usage

1. Clone this repository to your local machine.
2. Install the required gem:

```
bundle install
```

3. Open the terminal or command prompt.
4. Run the script with the year you are celebrating and the font you want to use as arguments:

```
./happy_new_year.rb 2025
# or
./happy_new_year.rb 2025 puffy
```
